GCal Widget

GCal Widget은 개인이 취미로 만든 무료 캘린더 위젯입니다. 구글 캘린더와 연동해서 데스크톱(Wallpaper Engine)에 월간/주간/일간 캘린더를 띄워주고, 음력·24절기 표시, 일정 추가/수정/삭제, 완료 체크 같은 기능을 제공합니다.

주요 기능

  • 월간 / 주간 / 일간 캘린더 보기
  • 구글 캘린더 일정 조회, 추가, 수정, 삭제 (본인 계정에 한함)
  • 대한민국 공휴일 자동 표시
  • 음력 날짜 및 24절기 표시
  • 일정 완료 체크 표시
  • 글꼴, 글자 크기, 색상 등 개인화 설정

구글 계정 연동에 대해

이 앱은 사용자가 원할 경우에만 구글 계정으로 로그인하여, 본인 소유의 캘린더 일정을 앱 화면에 표시하고 관리하는 데 사용합니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.
